# Way knowledge probe 1: questions

Written by Claudia Atlas from a first-time operator's point of view, without consulting the
guidance, so that the guidance doesn't shape the questions. These test C-001 and the
design's riskiest assumption. They are not the graded set REQ-001 will finally use, whose
pass mark is the operator's to set.

1. What is Arcadia, and what does it do for me?
2. I've never used this. What's the first thing I should do?
3. What's the difference between a Project, a Plan and an Action?
4. I have an idea for a client's website. How do I get started?
5. How do I tell Arcadia what I want from my phone?
6. How do I find out what needs my attention right now?
7. What's a Decision, and how do I answer one?
8. What happens if I ignore a Decision?
9. What can agents do without asking me?
10. Will Arcadia ever merge code without me?
11. Can it spend money or use my credentials on its own?
12. How does Arcadia decide which coding agent or model to use?
13. Which coding agents work with Arcadia?
14. How do I start production so work continues while I'm away?
15. How do I stop everything immediately?
16. What's the difference between an Ask and an Agent Ask?
17. I asked for something and it seems to have vanished. How do I find out what happened?
18. How do I see progress on a Plan?
19. A pull request an agent opened is failing. What do I do?
20. What's the Back Burner?
21. How do I restart Arcadia's services?
22. How do I add a new Project for a client?
23. How do I deploy a website through Arcadia?
24. Can Arcadia generate images or other media for my project?
25. How much will this cost me, and how do I keep spending down?
26. Where does my work live, and is it safe if a session crashes?
27. Can I use Arcadia from Discord or Slack?
28. Can a client message Arcadia directly?
29. How do I get a design reviewed before anything is built?
30. How do I teach Arcadia a lesson so it doesn't repeat a mistake?
