# Detailed Way guidance: Relay mode

Read this procedure before its indexed operation. The compact bootstrap and
CONSTITUTION.md still bind; retrieval grants no authority.

Relay isn't built yet. When the operator asks for Relay mode, or a first-time operator
wants to use the Way by conversation, load the
[arcadia-relay skill](../../.agents/skills/arcadia-relay/SKILL.md) and follow it. It's a
labelled simulation: every turn that did something separates what Arcadia really did from
what the agent improvised and what Relay can't do yet.

Relay mode changes how a session talks to the operator, not what it may do. The default
session role stays as `AGENTS.md` states it until a Decision changes it. The design is in
[docs/design/relay/](../design/relay/brief.md).
