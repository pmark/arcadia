# One press

This ran live on the operator's machine, against Arcadia's own repository.

On 31 October, the START card for Arcadia's first unattended run could not be made. The live worker ran from source with no binding, so no sign-in check could pass ([#1950](https://github.com/pmark/arcadia/issues/1950)). [Decision 0161](https://github.com/pmark/arcadia/blob/main/docs/decisions/0161-may-a-per-run-start-card-also-install-a-bound-worker-and-run-one-bounded-claude.md) let the card bind the worker and renew and check sign-in itself.

Each attempt after that stopped before START and named its cause. A host preflight found a process-ID mismatch ([#1954](https://github.com/pmark/arcadia/pull/1954)). Build noise in the install's JSON output stopped a press ([#1957](https://github.com/pmark/arcadia/pull/1957)). An absolute file path failed the diagnostic Ask and used up that day's sign-in renewal ([#1961](https://github.com/pmark/arcadia/pull/1961)). A settlement-scope check stopped the next ([#1964](https://github.com/pmark/arcadia/pull/1964)).

The operator's direction was: "no red tape is allowed to impede progress". [Decision 0162](https://github.com/pmark/arcadia/blob/main/docs/decisions/0162-remove-the-once-per-day-ceiling-on-claude-sign-in-renewal-and-worker-check.md) removed the daily renewal limit. [Decision 0163](https://github.com/pmark/arcadia/blob/main/docs/decisions/0163-may-the-operator-s-next-per-run-start-card-press-authorize-rowan-to-carry-that.md) let Rowan, the coordinating agent, press retry cards for this run, up to five attempts ([#1963](https://github.com/pmark/arcadia/pull/1963)).

At 06:40 UTC on 1 November, Rowan pressed card `start-run-unattended-20261101d`. It installed the reviewed revision, bound the worker, renewed sign-in, recorded [Decision 0164](https://github.com/pmark/arcadia/blob/main/docs/decisions/0164-authorize-one-start-card-worker-claude-usage-diagnostic-2026-10-31-777fb72e.md), checked usage, activated the Plan and reached START at 06:45.

## What is not done

As of 11:15 UTC, no work had been admitted for about four hours. Gates held two of the three Actions: a repair escalation carried over from the previous run, and a superseded Agent Ask, since rejected at the operator's choice. A planning approval then blocked the second, and the third was waiting to launch. Unattended delivery is still unproven. Six lessons from the night are on [#1929](https://github.com/pmark/arcadia/issues/1929).
