# Source-only worker Claude usage diagnostic — operator QA

Direct operator instruction, Issue #1736; no diagnostic Action was accepted. This change implements a fixed diagnostic, and creates no live grant, installation, activation, credential approval or governed completion. Production must stay Off.

Run only fakes in the candidate: `pnpm exec vitest run tests/worker-claude-usage-diagnostic.test.ts tests/provider-usage.test.ts`, `pnpm lint`, and `pnpm exec tsc --noEmit -p tsconfig.json`. The diagnostic tests create private fixture grants/Decisions and inject credential/provider functions. Check valid one-shot/concurrent replay, zero Codex/cache calls, extra-key/source/endpoint refusal, policy drift, missing/expired credentials,401/403/transport/parse distinctions, invalid/future reset windows, timeout/abort/late-loader fencing, restart consumption and serial worker ownership. Search receipts for the secret sentinel and its SHA256. Default provider-usage tests remain unchanged.

The nonce-only request path is `.arcadia/worker-claude-usage.request` under an already registered repository. The protected grant is `.arcadia/worker-claude-usage-grant.json` under the resolved workspace, mode0600. Its exact schema is ClaudeDiagnosticGrant in src/production/workerClaudeUsageDiagnostic.ts; no request chooses a command, endpoint, environment, path or source. An exact approved canonical Decision answer must bind the whole grant. No operator card or live grant is supplied by this PR.

Worker startup captures registered release/module identity, not current Git HEAD. Source-launched workers outside `~/.local/share/arcadia/go-broker/releases/<revision>` refuse. Future reviewed adoption must actually start the registered release's compiled worker before it can advertise a usable binding in `.arcadia/worker-claude-usage-heartbeat.json`. Installation/restart is a separate operator boundary. The manifest's registered source repository, runtime and role-registry hash plus fixed loaded module paths/hashes are checked. Hashes are code/grant identity only; no token-derived hash is emitted.

A future separately approved live probe must have exact repository/workspace/release/handler, Off revision/epoch, zero live admissions, nonce, fixed Claude/auto endpoint, expiry at most five minutes and deadline at most30seconds. It consumes a durable exclusive attempt before credentials. Timeout, crash or interruption permits no retry; recover retained attempt/receipt. Success requires HTTP200, both valid future5h/7d windows and exact worker binding/timestamps. One window, stale reset, signed-in or a shell response is insufficient. Receipts are under artifacts/worker-claude-usage; no shared telemetry is written by the diagnostic, no refresh token is exchanged, and it performs no inference.

No live credential exercise is part of QA. A diagnostic result is observation only and grants no production admission or START. Required independent current-head review/CI and any human merge/adoption gates remain separate.
