# Go workspace navigation

This linked Markdown outline is suitable input for a Markmap renderer. It is a proposed navigation model, not a rendered or tested Markmap artifact. Links open brief sections or source evidence; a prototype should map fictional object IDs to its own local work-area selections. Cross-links retain one identity per object. Plain outline navigation must remain usable without a map renderer.
