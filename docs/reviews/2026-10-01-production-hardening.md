# Production hardening after two adversarial reviews

This is a draft implementation proposal, not an activated Plan or a change to approval authority. The operator's confirmed goal is continuous improvement with little attention, initially one operator coordinating Projects with separate rules.

## Keep the architecture; repair the contracts

Project-owned governance preserves what work means and who may accept it. SQLite coordinates operational leases and receipts. Isolated candidates preserve recoverable work. The host owns writes that a coding sandbox cannot perform. These choices serve real requirements; the reviews did not justify replacing the orchestrator.

The expensive friction comes from gaps between those layers. A completion assertion must not outrun its evidence. A committed terminal receipt must not make unfinished integration disappear from the worker's next tick. Project restrictions must survive shared scheduling. Operator surfaces should expose one actual judgment and resume from its answer; mechanical recovery should not need a terminal or another coding Session.

## Findings and order

1. **Truthful completion — reproduced.** In temporary fixtures, a generic completed Run and a running Run each caused an unproven recovery criterion to be marked met under an acceptance Grant. Remove the fallback that fabricates criterion evidence. Reuse canonical settlements and drafted complete Asks; preserve automatic proof-based completion under Decision 0062.
2. **Durable integration recovery — follow-up fixture reproduction.** Terminal reconciliation releases the live lease before integration. With real drafted completion evidence and an unchanged valid Grant in a temporary fixture, an injected fast-forward failure left the next tick with no handoff to retry. This proves an integration-failure retry gap; a physical process-kill experiment remains unperformed. Rediscover existing receipts and recheck current exact authority; Off must continue to refuse integration.
3. **Separate Project rules — contract proof needed.** Prove one concrete Project-owned integration restriction, including wrong ownership, revocation and relevant approval drift. Another eligible Project should continue when one is blocked. Reuse adoption references, immutable packets and Grants; a hash alone does not enforce arbitrary prose.
4. **Qualified gate identity — source finding, full-dispatch impact unproven.** Test a Plan-qualified Ask target and the strongest other dispatch guards before changing its classification. Fix only demonstrated inconsistency.

The existing bootstrap implementation Actions for completion, reconciliation, preservation/integration and the false-completion gate are recorded done. These are new regression and recovery slices. The existing two-Action production proof retains its own acceptance criteria; this proposal does not mark it complete or replace it.

The paired Agent Ask requests a new inactive draft Plan. Accepting a draft would still not activate it or supply production authority. Deterministic tests precede further live provider spend; retry loops receive no new model budget.

## Deferred work and verification

Flight Deck expansion waits for the narrow production proof. Extra provider concurrency waits for a real workload or clean single-provider use. Independent human approvers wait for a second approver. A replacement engine waits for evidence that several independent recovery owners or repeated regressions cannot be removed through the existing contracts.

Before widening production, propose a small installed-trial threshold to the operator; three consecutive bounded two-Action passes is a candidate, not adopted policy. Record attempts, model calls when measurable, recovery latency, runtime revision and every intervention. Distinguish candidate completion, base integration and broader readiness.

Both reviewers used fresh GPT-6 Astra contexts at high reasoning; the second received the original packet and first report. The synthesis corrected candidate/base confusion and rejected speculative replacement scope. Local review artifacts retain the full reports and evidence. Token cost was not measured.
