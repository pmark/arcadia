# Living-system v1 morning demo

## Open this first

Open the **Arcadia1** vault in Obsidian, then open:

`Projects/arcadia/Home.md`

The first screen answers what Arcadia is for, names the current living-system
Action, links directly to the two capabilities it affects, reports evidence
freshness, and offers four depths: Glance, Orient, Understand, and Audit.

## Two-story walkthrough

### Arcadia — intent to governed delivery

1. From Home, open **Whole system** or
   `Maps/View_whole-system.md`.
2. Follow the eight-capability loop: Capture intent → Clarify the next Action →
   Prioritize the portfolio → Govern the plan → Execute the build → Prove
   quality → Deliver the result → Preserve living memory.
3. Open **Preserve living memory**, then an Action episode, then follow its
   reciprocal Topic link back. Status, provenance, freshness, Decisions, proof,
   and continuation remain visible.
4. Open `Living_System.canvas` for the capability map and Action timeline beside
   Current Work.

### Private Practice Now — practitioner evidence to trusted launch

1. Open `Projects/private-practice-now/Home.md`.
2. Open **Practitioner to trusted launch** or
   `Maps/View_practitioner-to-launch.md`.
3. Follow the ten-step journey: Practitioner interview → Structured evidence →
   Normalized practitioner profile → Authentic section copy → Human copy
   acceptance → Explainable site assembly → Independent client repository →
   Staging proof → Inquiry delivery → Trusted launch.
4. Return Home. The real current copy-calibration Action links directly to
   **Authentic section copy** and the downstream **Human copy acceptance**
   boundary. Missing historical evidence remains visibly missing.

For either map, use Obsidian's command palette and search for Mindmap to open a
Mindmap NextGen pane. Ordinary Reading View is the intentional no-plugin
fallback.

  Normalize legacy sources only if those Signals repeatedly prevent a real

- Add an explicit Action `affects` field only if reference and changed-file
  matching misses important impacts again after these two dogfood Projects.

  only when repeated use fires the corresponding Decision 0032 trigger.

## Rollback

Generated subtrees are projections, not authority. To rebuild, preserve or
remove only `Projects/arcadia/` or `Projects/private-practice-now/`, then run
sync after the corresponding PR is merged. To restore the pre-demo plugin
state, close Obsidian and follow the backup README. No routine sync downloads,
installs, or upgrades plugin code.
