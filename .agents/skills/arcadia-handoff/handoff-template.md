# Objective

One concrete outcome; Project / Plan / Action, or explicitly no assigned Action.

# Verified state

- Completed: proven facts or edits already made
- Files inspected: only relevant paths
- Files changed: paths from actual Git status/diff, including untracked work
- Tests: exact command, result and revision tested; failures and checks not run
- Technical conclusion: conclusion and evidence that should not be rediscovered
- Governed Decisions: references and remaining gates

# Resume location

Repository/worktree, branch, exact HEAD, PR and evidence references. Recorded main
checkpoint cursor when applicable. Distinguish committed, pushed and local-only
work. Identify running operations and how to reconcile their results.

# Authority and custody

Current owner/Session; claim or generation if known; actual transfer status;
approvals still required; existing wakeup state. Unknown stays unknown.

# Unresolved

Blockers, uncertainties, failed approaches and evidence needed before retrying.
Canonical references for follow-up work.

# Handoff reason

Outcome: continue / prepare / recommend handoff. Basis: measured / heuristic.
Observation source and time; provider/version and counting scope when measured;
headroom or unknown; next-step estimate, preservation allowance and uncertainty.
Safe stopping point. Recommendation and actual transfer are separate facts.

# Next action

One exact edit or diagnostic, including target path or command when known.

# Stop condition

The test, diff or output that proves completion. A new session or a written
handoff does not prove Action completion.
